# Design review specimens

These HTML files preserve the reviewed proposal alongside its documentation. They are experiments and historical comparisons, not mandatory app layouts or screenshot baselines. The later component galleries and complete reading journey carry the selected literary-serif direction; the initial foundation and typography comparison retain earlier alternatives.

Open the HTML files in a browser, or serve this directory locally. Earlier studies request fonts from Google Fonts; later galleries embed the pinned Armenian fonts and use Google Fonts for Source Serif. Some icon examples request a pinned Ionicons CDN asset. These dependencies are preserved to avoid silently changing the reviewed artifacts. Use the isolated native experiment and the eventual app adapters for pinned-asset runtime checks.
