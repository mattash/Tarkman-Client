# Tarkman design trial foundation

This framework-free package supplies candidate semantic color data and generated CSS for application trials. It has no runtime dependencies and contains no React, DOM, React Native, navigation, or icon code.

`tokens.json` is the source. Regenerate `web.css` with `npm run build --prefix packages/tarkman-design` and verify it with `npm run check --prefix packages/tarkman-design`. The API and values remain provisional while the application trial is reviewed.
